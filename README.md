# 視力自我檢查 Vision Test

一個純前端、免安裝的手機視力自我檢查工具。用信用卡校正螢幕比例後，用 E 字視標（Tumbling E）分別檢查左右眼或雙眼綜合視力，並把每次結果留存在裝置本機，方便長期追蹤變化。

線上使用：**https://seeuda.github.io/vision-test/**（用手機瀏覽器打開即可，不需要帳號、不需要安裝）

## 功能

- **螢幕校正**：用信用卡／健保卡（85.6mm）直放比對，換算螢幕實際像素密度，確保視標尺寸準確
- **標準視力檢查**：國際標準十進位視力表級距（0.01 ~ 1.25，每級固定約 1.26 倍差距），統一從 0.04 開始，依答對/答錯自動升降級
- **三種檢查範圍**：左右眼分別（遮眼）、只測單眼、雙眼綜合（不遮眼，反映日常生活實際視力）
- **長者／低視力模式**：自動切換 25cm 近距離、放大文字與按鈕、提醒白內障患者不必用最大亮度
- **歷史紀錄**：折線圖呈現左眼／右眼／雙眼隨時間的變化，可勾選個別刪除（附刪除前確認），可匯出 CSV
- **結果一律左眼在左、右眼在右**，跟自己身體方位一致

## 使用方式

1. 打開網頁，先做「螢幕校正」（只需做一次，除非換手機）
2. 選擇觀看距離、檢查範圍、受檢者狀況
3. 依畫面指示測試，看不清楚就按「看不清楚」，不要用猜的
4. 完成後可在「歷史紀錄」查看趨勢圖與逐筆紀錄

## 技術說明

- 單一 `index.html` 檔案，React + Babel 皆透過 CDN 載入，不需要建置流程，可直接放上 GitHub Pages 或任何靜態空間
- 紀錄使用瀏覽器 `localStorage` 儲存在**使用者自己的裝置**上，不會上傳到任何伺服器；換裝置或清除瀏覽資料會遺失紀錄
- 修改後重新部署時，建議用無痕視窗或加上 `?v=數字` 網址參數測試，避免瀏覽器快取顯示舊版本

## 重要限制（請詳讀）

這是居家自我追蹤工具，**不是醫療器材，不能取代眼科／驗光師的正式檢查**：

- 只測「視力（acuity）」，測不出視野缺損、對比敏感度下降、畏光等問題（例如中風視野缺損、白內障的眩光症狀）
- 結果會受螢幕亮度、環境光線、觀看距離、手機機型與螢幕解析度影響；同一人請盡量固定這些條件，前後比較才有意義
- 手機螢幕在近距離下能測到的視力上限有其物理極限（螢幕解析度所致），並非受檢者實際視力的絕對值
- 若發現兩眼落差明顯、視力持續下滑，或有其他不適，請盡速就醫
